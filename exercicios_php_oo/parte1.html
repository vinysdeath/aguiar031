1 O que é encapsulamento?

Responda com suas próprias palavras:

O que significa encapsular dados em uma classe?

Encapsular dados em uma classe significa proteger esses dados, ocultar detalhes internos e controlar o acesso a eles através de uma classe.

Qual é a diferença entre um atributo public, protected e private?

Public: acessível através de qualquer lugar do código. Protected: acessível apenas pela própria classe e suas subclasses. Private: acessível apenas pela própria classe

Por que não é boa prática deixar todos os atributos como public?

Deixar todos os atributos públicos pode comprometer a integridade dos dados.

2 Para que servem os métodos get e set?

Por que usamos getAtributo() ao invés de acessar $objeto->atributo diretamente?

Usamos getAtributo() para controlar o acesso ao atributo, porque não é possível acessar diretamente atributos private.

O que um método set pode fazer além de simplesmente atribuir um valor?

Um método set pode validar o valor antes de atribuir, garantindo que os dados sejam consistentes e válidos.

Dê um exemplo prático de validação dentro de um set.

Um setIdade($valor) pode verificar se $valor > 0 antes de salvar. Isso protege o objeto de receber dados invalidos.

3 Verdadeiro ou Falso — encapsulamento

Teoria Classifique cada afirmação como Verdadeiro (V) ou Falso (F) e justifique:

"Um atributo private pode ser lido diretamente fora da classe." (Falso)
Justificativa: Acesso a atributos private só é possível dentro da própria classe.

"Getters e setters so fazem sentido quando os atributos sao private." (Verdadeiro)
Justificativa: São necessários para controlar o acesso a atributos private.

"Encapsulamento aumenta a seguranca e a manutencao do codigo." (Verdadeiro)
Justificativa: Facilita a manutenção e melhora a segurança dos dados.

"E possivel ter um getter sem ter um setter para o mesmo atributo." (Verdadeiro)
Justificativa: Permite ler o valor de um atributo private sem permitir que ele seja modificado externamente.
